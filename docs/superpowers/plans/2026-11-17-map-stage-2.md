# Map Stage 2 Implementation Plan: instruments in shapes

**Goal:** Each shape plays a Studio instrument with its own settings (preset, Vary, palette, speed), changed live without the wall going black, editable in Studio and back, at the measured frame rate.

**Architecture:** See "Stage 2 decisions" in the design. Pure logic in `src/map/` (show v2, content edits, wire messages, sizing, governor, fade, clock), tested with `node:test`. `src/map/compositor.ts` owns one `StudioRenderer` per instrument source and draws shapes with Canvas 2D clipping. The output page and the operator screen (output closed) both use it.

**Spec:** [docs/projection-mapping-design-2026-11-16.md](../../projection-mapping-design-2026-11-16.md): Build order stage 2 row, "Content: what plays in a shape", "Stage 2 decisions".

**Execution:** native (the controller implements), with an independent review after Tasks 4–5 and Task 7, and a whole-branch review at the end.

## Global Constraints

- Studio's loops, seeking and export must not change. Existing Studio and Live tests pass untouched.
- No edit may blank the output. A source that is not ready yet keeps the previous picture.
- No mapping jargon on screen ("slice", "surface", "UV", "homography", "input", "output" — except the agreed "Open output"/"Close output").
- Limits: 64 shapes, 64 sources, 4 layers per composition (Studio's limit), names 40 characters.
- Messages: show message ≤ 256 KB; a source message ≤ 24 MB.
- Studio's own project, history and autosave are never overwritten by Edit in Studio.

## Review Focus

1. **A source that fails to prepare** (a broken composition): the shape keeps its last picture (or its colour), the operator sees why, the other shapes are untouched. Test: Task 4 (compositor state) and Task 8 (in-app).
2. **Deleting a shape whose source is shared or orphaned**: no orphan sources stay in the file; a shared source stays. Test: Task 2.
3. **App closed while editing a shape in Studio**: Studio's own autosave holds Studio's own project, and the shape keeps the latest edit. Test: Task 7.
4. **Output opened after sources were sent to a previous output**: every source is re-sent. Test: Task 3 (sent-revision tracking resets on open).
5. **Very slow machine**: the governor steps down before the frame rate drops, and steps back up. Test: Task 4.

### Task 1: Show version 2 — sources and shape content

**Files:** Modify `src/map/show.ts`; Test `tests/map-show.test.ts`.

**Interfaces (produces):**
```ts
export interface InstrumentSource { id: string; kind: 'instrument'; project: Project; speed: number; revision: number }
export type Source = InstrumentSource;
export interface Shape { /* stage 1 fields */ sourceId: string | null }   // null: plays its colour
export interface ShowDocument { format: 'formshow'; version: 2; stage; shapes: Shape[]; sources: Source[] }
export const MAX_SOURCES = 64; export const SPEED_RANGE = { min: 0.1, max: 4 };
```
- `validateShow` accepts version 1 (no sources; every `sourceId` null) and 2. Each source's project goes through `validateProject` (src/core/project.ts); a source whose project fails is dropped and shapes using it fall back to colour (`repaired`). Speed clamped to range; revision a non-negative integer. A shape whose `sourceId` names no source falls back to colour. Sources no shape uses are dropped. Ids over 64 characters replaced (as shapes).

Tests: v1 file loads with `sourceId: null` and `sources: []`; v2 round-trips; a broken project drops its source and the shape plays colour; unknown `sourceId` → colour; orphan source dropped; speed clamped; 65 sources → 64.

### Task 2: Content edits

**Files:** Modify `src/map/editor.ts`; Test `tests/map-editor.test.ts`.

**Interfaces:**
```ts
| { type: 'setContent'; shapeId: string; content: { kind: 'colour' } | { kind: 'preset'; presetId: string; sourceId: string; seed: number } }
| { type: 'varySource'; sourceId: string; entropy: number }
| { type: 'setSourcePalette'; sourceId: string; palette: string[] }
| { type: 'setSourceSpeed'; sourceId: string; speed: number }
| { type: 'setSourceProject'; sourceId: string; project: Project }
| { type: 'duplicate'; shapeId: string; id: string; sourceId?: string }   // sourceId: the copy's own source
```
- `setContent` preset: builds a one-layer composition with `createProject`, `createLayer(kind)`, `applyPreset`, seed; replaces the shape's own source if it has one used only by it, else adds a new source. Colour: the shape's source is dropped if no other shape uses it. Locked shapes refuse.
- Every source change increments `revision`. `varySource` uses `varyLayer` on each layer with strength 0.5 and no locks. Palette: 2–8 `#rrggbb` colours, applied to each layer. Speed clamped. `setSourceProject` runs `validateProject`; refused when invalid, or over 4 layers.
- `duplicate` copies the source too (new id given by the caller); `delete` drops the shape's source when no other shape uses it. Undo covers all of it (whole-show snapshots).

Tests: one per action, plus locked refusal, orphan cleanup on delete and on set-colour, duplicate gets a separate source, revision increments, `MAX_SOURCES` refusal.

### Task 3: Messages for sources

**Files:** Modify `src/map/messages.ts`, `electron/map.cjs` (mirror), `src/ui/MapOutput.tsx` (`applyMapMessage`); Tests `tests/map-editor.test.ts`, `electron/map.test.cjs`.

**Interfaces:**
```ts
| { type: 'show'; show: WireShow }          // sources without projects: { id, kind, speed, revision }
| { type: 'source'; id: string; revision: number; project: Project }
| { type: 'freeze'; on: boolean }
export const SOURCE_MESSAGE_LIMIT = 24 * 1024 * 1024;
export function toWire(show): WireShow;
export function sourcesToSend(show, sent: Map<string, number>): { messages: MapMessage[]; sent: Map<string, number> }  // pure
```
- `acceptMapMessage`: 'source' messages have their own limit; everything else stays at 256 KB. Both copies change together; a parity test runs one table of accept/reject cases against both.
- The operator tracks which source revisions the open output has; the record resets whenever the output opens (Review Focus 4).
- `applyMapMessage` keeps `projects: Map<id, { revision, project }>`; a 'source' message older than the held revision is ignored.

### Task 4: Compositor

**Files:** Create `src/map/compositor.ts` (class) and `src/map/playout.ts` (pure parts); Test `tests/map-playout.test.ts`.

**Pure interfaces (`playout.ts`):**
```ts
export function sourceSize(points: Point[], scale: number): { width: number; height: number }   // bbox in stage px × scale, clamped 64..1920×1080, integers
export function advancePhase(phase: number, seconds: number, project: Project, speed: number): number  // playbackPhase with duration
export interface Governor { level: 0 | 1 | 2 | 3; slow: number; fast: number }
export const GOVERNOR_SCALES = [1, 0.75, 0.5, 0.5];   // level 3 also draws instruments every other frame
export function governorStep(g: Governor, frameMs: number): Governor   // 30 slow frames (>15 ms) step down; 120 fast (<10 ms) step up
export function fadeAlpha(startedMs: number, nowMs: number, durationMs = 400): number
```
**Class:**
```ts
export class MapCompositor {
  constructor(canvas: HTMLCanvasElement);
  setShow(show: ShowDocument | WireShow, projects: Map<string, Project>): void;
  setOptions(options: DrawOptions & { freeze: boolean }): void;
  frame(nowMs: number): void;           // advance clock, render sources, composite, overlays
  stats(): { fps: number; level: number; failing: string[] };   // failing: source ids that could not prepare
  dispose(): void;
}
```
- One `StudioRenderer` per source id, on its own canvas; disposed when the source leaves the show. `prepare(project)` is async: until it resolves, the shape draws its previous picture (fade snapshot) or its colour.
- Drawing: for each visible shape back to front: instrument shape → clip to outline, draw the source canvas covering the outline's bounding box (Fit); colour shape → fill. Then the stage 1 overlays (`stageCommands` with `outlinesOnly` for test grid, identify, selection, crosshair) and blackout.
- Fade: when a shape's source id changes, or a source's project is replaced with a different set of layer kinds, snapshot the shape's last picture and crossfade once the new source is ready.

Tests (pure): sizing (small, huge, scaled, degenerate); phase advance with speed and evolving compositions; governor stepping down, holding, stepping up, not flapping; fade alpha 0→1.

### Task 5: Output page plays sources

**Files:** Modify `src/ui/MapOutput.tsx`, `electron/map.cjs`, `electron/preload.cjs`, `src/shared/types.ts`; Test `electron/map.test.cjs`.
- MapOutput runs `MapCompositor` in a `requestAnimationFrame` loop. Every second it reports `{ fps, level, failing }` to the studio on a new channel `studio:map:state` (checked in the main process: from the output only, small plain object). Picture previews continue.

### Task 6: Operator content controls

**Files:** Modify `src/ui/MapPanel.tsx`, `src/ui/useMap.ts`, `src/ui/map.css`.
- Details panel, "Content": Colour or an instrument from the Library (grouped by instrument, the same presets as Studio); for an instrument: Vary, palette (the named palettes in `src/core/palettes.ts`, plus the preset's own), speed slider (0.1–4, 1 = as designed). Right-click menu gains "Vary".
- With the output closed, the operator canvas runs its own `MapCompositor`; with it open, it shows the wall's picture (stage 1 behaviour). Status line shows the output's frame rate and any reduction ("Drawing instruments at 75 %").
- Freeze button in the header (sends 'freeze').

### Task 7: Edit in Studio and back

**Files:** Modify `src/ui/App.tsx`, `src/ui/useMap.ts` (session API: `beginStudioEdit`, `studioEdit`, `endStudioEdit`); Test: a pure helper `src/ui/studio-edit.ts` with `tests/studio-edit.test.ts`.
- "Edit in Studio" (Details panel and menu) switches to Studio with a bar "Editing <shape> from Map · Back to Map". App stashes `{ project, history, future, filePath, selectedId }`; Studio's autosave effect and its close handler save the stashed project while editing. Each change is sent to the Map session (`setSourceProject`, throttled to one per frame). Back to Map (or switching to Map/Live) restores the stash. Export and Open/Save of `.formfield` are disabled while editing.

### Task 8: In-app check, performance record, design notes

**Files:** `scripts/verify-map.mjs`; the design doc.
- Checks: an instrument in a shape draws a changing, non-black picture inside the shape and black outside; two shapes with different instruments differ; changing one shape's preset never blacks the wall (sample every frame during the swap) and does not re-prepare the other shape's source (a debug counter on `window.__mapStats`); Freeze stops change; Edit in Studio round trip keeps Studio's project.
- Performance: eight shapes, four instruments, 1920 × 1080 output, 30 s: median and 95th percentile frame time, governor level. Written into the design under "Stage 2 results", with what it does not show.
