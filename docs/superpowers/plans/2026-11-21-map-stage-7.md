# Map Stage 7 Implementation Plan: wild options

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Six wild options, each off by default and working on its own:
- Outline drives the instrument
- Stagger
- Vary each
- Palette shift
- Border runs
- Scene auto-advance

**Done when:**
- Each option has a scripted in-app check that shows it working on the wall.
- With every option off, the wall is exactly as in stage 6.
- `npm run test:map` passes.
- `measure-map --wild` (the eight-effect show, one group staggered, two border runs) stays at the display's rate with the governor at level 0.

**Architecture:**
- **New saved fields** (show version 8):
  - `InstrumentSource.followOutline`
  - `Group.stagger`, `Group.chase`
  - `Border.run`
  - `ShowDocument.autoAdvance`
- **Vary each and Palette shift** are editor actions that make separate copies.
- **The compositor** gains:
  - a frame history per staggered source
  - a draw-time surface override (outline)
  - a border-position texture with a run uniform
- **Auto-advance** is a timer in `useMap`, beside the triggers.

**Tech Stack:** as stage 6.

**Spec:** "Stage 7 decisions: wild options" in [docs/projection-mapping-design-2026-11-16.md](../../projection-mapping-design-2026-11-16.md), and its "Wild options" and Stagger lines.

**Branch:** `map-stage-5`, in the `three VJ - main` folder. No branch switching, and no push or merge without Greg's say-so.

**Execution:** native. Independent reviews after Task 3 (the drawing changes) and across the whole work at the end.

## Global Constraints

- **Off by default:** with every option off, nothing changes on the wall, in the show file (beyond version 8) or in performance.
- **The wall never goes black** when an option is switched on or off.
- **Limits:**
  - Stagger 0 to 1 s
  - frame history at 30 a second, kept only while a staggered group plays the source
  - outline simplified to at most 12 points
  - border run speed 1 to 120 laps a minute, or with the tempo every 1, 2, 4, 8 or 16 beats; length 2 to 50 % of the outline
  - auto-advance every 5 s to 10 min, or every 1 to 64 bars
- **Undo:** Vary each and Palette shift are one undo step each. Auto-advance changes share one step, as triggers do.
- **Unchanged:** Studio, Live, and the show's compositions as saved.

## Review Focus

1. **A staggered group whose shapes change order, or a shape leaving it.** The delays follow the new order at once, with no black frame. → Task 3 check.
2. **Outline drives with a shape whose outline is being dragged.** The instrument follows without stalling the drag (the surface is rebuilt at most once a frame). → Task 3, throttled rebuild.
3. **Vary each on a group that would pass the 64-source limit.** It is refused with a note, nothing changes, and there is still one undo step. → Task 1 test.
4. **Auto-advance with a single scene, or with Freeze on.** Nothing switches, and nothing errors. → Task 1 test of `nextAutoScene`; Task 4 check.
5. **A border run on a shape with holes or curves.** It runs round the outer outline only, at an even speed along curves. → Task 2 test of the outline measure.

### Task 1: The show (version 8) and the rules

**Files:**
- Modify:
  - `src/map/show.ts`: the new fields, their readers and version 8
  - `src/map/editor.ts`: the actions below
- Create: `src/map/wild.ts`: the pure rules
- Test: `tests/map-wild.test.ts`

**Interfaces:**
- Produces:
  - **Fields:**
    - `InstrumentSource.followOutline: null | 'obstacle' | 'emitter' | 'edge'`
    - `Group.stagger: number` (0..1 s)
    - `Group.chase: boolean`
    - `Border.run: null | { lapsPerMinute: number; beats: number | null; length: number }`
    - `ShowDocument.autoAdvance: null | { every: number; unit: 'seconds' | 'bars'; order: 'next' | 'random' }`
  - **Edit actions:**
    - `{ type: 'setFollowOutline'; sourceId; mode }`
    - `{ type: 'setGroupStagger'; groupId; seconds }`
    - `{ type: 'setGroupChase'; groupId; on }`
    - `{ type: 'setBorderRun'; shapeId; run }`
    - `{ type: 'setAutoAdvance'; autoAdvance }`
    - `{ type: 'varyEach'; groupId; sourceIds: string[]; entropy: number }`
    - `{ type: 'paletteShift'; groupId; sourceIds: string[] }`
  - **`wild.ts`:**
    - `staggerDelays(show, groupId): Map<shapeId, seconds>`: list order; the first shape 0, the last `stagger`
    - `chaseOffsets(show, groupId): Map<shapeId, number>`: 0..1, list order
    - `rotatePalette(palette: string[], steps: number): string[]`
    - `outlinePolygon(points: CurvePoint[], box): { x; y }[]`: at most 12 points in the box's 0..1 space, y up, keeping the most significant corners
    - `nextAutoScene(show, current: string | null, random: () => number): string | null`: null with fewer than 2 scenes; random never repeats the current one
    - `autoAdvanceDue(setting, elapsedS, bars): boolean`
