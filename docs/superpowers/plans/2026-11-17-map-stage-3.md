# Map Stage 3 Implementation Plan: the full drawing kit

**Goal:** Trace and line up a scene of about 20 pieces in one sitting: Pen with straight and curved sides, triangle, ellipse, point editing, holes, Snap with joined corners, a trace-over Photo, multi-selection with scale, turn, flip and mirror, Make a grid, groups, lock/hide/solo, soft edge, border and Blockers.

**Architecture:** See "Stage 3 decisions" in the design.
- The geometry is pure and tested with `node:test`:
  - `src/map/outline.ts`: curves, holes, validity, hit tests, transforms, grid cells
  - `src/map/snap.ts`
- The show moves to version 3 (`show.ts`), and the editor gains the new actions (`editor.ts`).
- Drawing, both the operator's (`draw.ts`) and the wall's (`compositor.ts`), builds each shape as one path with curves and holes, using the even-odd rule.
- Soft edges come from a fade picture cached per shape. Borders and Blockers are drawn in the same pass.
- The operator screen (`MapPanel.tsx`) gains the tools and gestures. The pointer logic that can be pure (what a press grabs, what a drag does) lives in `src/map/gestures.ts`.

**Spec:** [docs/projection-mapping-design-2026-11-16.md](../../projection-mapping-design-2026-11-16.md): Build order stage 3 row, "Drawing shapes", "Lining up on the real object" (Photo), "Look, edge and timing" (Edge), "Stage 3 decisions".

**Execution:** native (the controller implements). Independent reviews:
- after Tasks 1–3 (format and geometry)
- after Task 6 (compositor)
- a whole-branch review at the end

## Global Constraints

- Studio's loops, seeking and export must not change. Studio and Live tests pass untouched.
- No edit may blank the output. A refused outline keeps the last valid one on the wall.
- No mapping jargon on screen. The tool words are Pen, Rectangle, Triangle, Ellipse, Select, Hole, Snap, Photo, Group, Solo, Blocker, Soft edge, Border, Make a grid, Flip, Mirror.
- Version 1 and 2 shows open unchanged in meaning. The show file stays one JSON document.
- Limits:
  - 64 shapes
  - 32 points a shape, holes included
  - 8 holes a shape
  - 32 groups
  - 64 sources
  - names 40 characters
- The largest valid show message still fits `MAP_MESSAGE_LIMIT`, tested. The photo never travels to the wall.
- Performance holds: `scripts/measure-map.mjs` keeps 120 fps with no frame over 16.7 ms. This includes a new run with soft edges and borders on all eight shapes.

## Review Focus

1. **Curved or holed outlines that cross.** This covers a curve bulging over a neighbouring side, and a hole touching the outline. They are refused, drawn red on the operator screen, and the wall keeps the last good outline. Tests: Tasks 1, 3 and 9.
2. **Version 2 file with stage 2 sources.** It opens with every source and shape intact and no repair notice. Test: Task 2.
3. **Joined corners where one shape is locked or the move is refused.** A locked shape's corner stays put, and the others still move. If any touched outline would be refused, nothing moves. Test: Task 3.
4. **Make a grid past the limits** (more than 64 shapes or 64 sources): refused whole, never half made. Test: Task 3.
5. **Photo never reaches the wall.** `toWire` drops it, the wall's picture never contains it, and the autosave still keeps up with a 4 MB photo. Tests: Tasks 5 and 9.
6. **Soft edge cost.** Fade pictures are rebuilt only when the shape changes, not every frame. Tests: Task 6, with a counter, and Task 9 (performance).

### Task 1: Outline maths

**Files:** Create `src/map/outline.ts`. Test: `tests/map-outline.test.ts`.

**Interfaces:**
```ts
export interface Handle { x: number; y: number }                  // offset from its point, stage fractions
export interface CurvePoint extends Point { in?: Handle; out?: Handle }
export type Ring = CurvePoint[];
export const CURVE_STEPS = 16;
export function isCurved(p: CurvePoint): boolean;
export function flatten(ring: Ring, steps?: number): Point[];      // straight sides kept as is, curved sides in CURVE_STEPS pieces
export function ringBounds(rings: Ring[]): { x0: number; y0: number; x1: number; y1: number };
export function shapeValidity(outline: Ring, holes: Ring[]): { ok: true } | { ok: false; reason: 'crossing' | 'collapsed' | 'too-few' | 'too-many' | 'outside' | 'hole-outside' | 'too-many-holes' };
export function hitShape(at: Point, outline: Ring, holes: Ring[]): boolean;          // inside the outline and not in a hole
export function nearestSide(at: Point, ring: Ring): { index: number; t: number; distance: number };  // stage px distance
export function insertPoint(ring: Ring, side: number, t: number): Ring;    // de Casteljau split keeps a curved side's shape
export function removePoint(ring: Ring, index: number): Ring;
export function setCurve(ring: Ring, index: number, curved: boolean): Ring; // curved: smooth handles from the neighbours
export function moveHandle(ring: Ring, index: number, which: 'in' | 'out', to: Point, mirror: boolean): Ring;
export function ellipseRing(a: Point, b: Point): Ring;                     // 4 curve points, kappa 0.5523, in stage px space
export function triangleRing(a: Point, b: Point): Ring;
export function squareBox(a: Point, b: Point): Point;                      // b moved so the box is square in projector pixels
export function transformRing(ring: Ring, m: Matrix): Ring;                // m in projector pixels; handles get the linear part
export type Matrix = [number, number, number, number, number, number];
export function scaleAbout(pivot: Point, sx: number, sy: number): Matrix; export function rotateAbout(pivot: Point, radians: number): Matrix;
export function gridCells(quad: Point[], rows: number, cols: number, gapPx: number): Point[][];  // bilinear, gaps in projector px
```
- `shapeValidity` replaces the body of `isValidOutline`. Old callers keep `isValidOutline(points)`, which is now `shapeValidity(points, [])`.
- The anchor rules stay as they were: on the stage, no repeated anchor, at least 3. The crossing and area rules run on the flattened ring.
- Holes:
  - each hole is valid on its own
  - no hole side meets an outline side or another hole's side
  - every flattened hole point is inside the outline
  - every hole lies outside the other holes
- The total anchor count is at most `MAX_POINTS`, and there are at most 8 holes.

**Tests:**
- A square is valid.
- A curve bulging over the opposite side is a crossing.
- An S-curve side is valid.
- A hole inside is valid.
- A hole touching the outline gives `hole-outside`.
- Two overlapping holes are refused.
- A hole inside a hole is refused.
- 9 holes gives `too-many-holes`.
- Anchors over 32 in total gives `too-many`.
- Hit test: inside the outline but in a hole is false.
- Splitting a curved side leaves the flattened outline within 0.5 px of the original.
- Removing a point down to 2 is refused by the validity check.
- Smooth handles are collinear.
- Mirrored handle moves keep collinearity, and Alt (no mirror) does not.
- Ellipse: 4 points; its flattened ring stays within 0.3 % of a true ellipse.
- Transforms: rotating 90° about the centre and back is the identity; flipping twice is the identity.
- Grid: a 2×2 grid of a square with a 0 gap tiles it exactly; a gap leaves that many pixels; a skewed quad gives cells whose shared corners meet.

### Task 2: Show version 3

**Files:** Modify `src/map/show.ts`. Test: `tests/map-show.test.ts`.

**Interfaces:**
```ts
export interface Shape { /* v2 */ points: CurvePoint[]; holes: Ring[]; groupId: string | null; blocker: boolean; softEdge: number; border: Border }
export interface Border { width: number; colour: string | 'palette'; glow: number }
export interface Group { id: string; name: string; visible: boolean; locked: boolean }
export interface Photo { data: string; opacity: number }   // data: 'data:image/jpeg;base64,…', ≤ 6 MB of text
export interface ShowDocument { version: 3; /* … */ groups: Group[]; photo: Photo | null }
export const MAX_HOLES = 8, MAX_GROUPS = 32, SOFT_EDGE_MAX = 200, BORDER_MAX = 40, GLOW_MAX = 40;
export function isShapeLocked(show, shape): boolean; export function isShapeShown(show, shape): boolean;  // own setting and group's
export function normaliseGroups(show): ShowDocument;    // members together, empty groups dropped
```
- Validation:
  - Handles: finite, each part clamped to ±1. A bad handle is dropped, and the point becomes a corner (`repaired`).
  - A hole that fails is dropped; the shape stays.
  - Missing v3 fields take their defaults without `repaired`.
  - A `groupId` naming no group becomes null.
  - Group members are made contiguous; that counts as a repair.
  - A photo that is not a `data:image/(jpeg|png);base64,` string, or is over the size limit, is dropped.
  - A blocker's `sourceId` is set to null.
- `validateWireShow` reads the same shape fields. Wire shows have no photo.

**Tests:**
- A v1 file and a v2 file (stage 2 fixture) load with defaults and `repaired: false`.
- A v3 file round-trips.
- A bad handle becomes a corner.
- A crossing hole is dropped.
- An unknown group becomes null.
- Split group members come back together, in order.
- A bad photo is dropped.
- 33 groups are cut to 32.
- A blocker with a source is cleared.

### Task 3: Editor actions

**Files:** Modify `src/map/editor.ts`. Test: `tests/map-editor.test.ts`.

**New actions:**
```ts
| { type: 'addShape'; id: string; points: CurvePoint[]; colour: string; name?: string }       // rectangle, triangle, ellipse, pen
| { type: 'addHole'; shapeId: string; points: CurvePoint[] }
| { type: 'movePoint'; shapeId; index; to; ring?: number; joined?: boolean }                // ring: -1/undefined outline, 0.. a hole
| { type: 'nudgePoint'; …; ring?: number; joined?: boolean }
| { type: 'insertPoint'; shapeId; ring?: number; side: number; t: number }
| { type: 'removePoint'; shapeId; ring?: number; index: number }   // a hole down to 2 points removes the hole
| { type: 'setCurve'; shapeId; ring?: number; index: number; curved: boolean }
| { type: 'moveHandle'; shapeId; ring?: number; index: number; which: 'in' | 'out'; to: Point; mirror: boolean }
| { type: 'moveShapes'; shapeIds: string[]; dx: number; dy: number }
| { type: 'transformShapes'; shapeIds: string[]; matrix: Matrix }           // scale, turn, flip
| { type: 'deleteShapes'; shapeIds: string[] }
| { type: 'duplicateShapes'; shapeIds: string[]; ids: string[]; sourceIds: string[]; offset?: { dx: number; dy: number } }   // Alt-drag passes the drag
| { type: 'mirrorShapes'; shapeIds: string[]; axis: 'vertical' | 'horizontal'; ids: string[]; sourceIds: string[] }
| { type: 'makeGrid'; shapeId: string; rows: number; cols: number; gapPx: number; ids: string[]; sourceIds: string[]; groupId: string }
| { type: 'group'; shapeIds: string[]; groupId: string; name: string } | { type: 'ungroup'; groupId: string }
| { type: 'renameGroup'; groupId; name } | { type: 'setGroupVisible'; groupId; visible } | { type: 'setGroupLocked'; groupId; locked }
| { type: 'reorderGroup'; groupId; to: 'front' | 'back' | 'forward' | 'backward' }
| { type: 'setBlocker'; shapeId; blocker: boolean } | { type: 'setSoftEdge'; shapeId; px: number } | { type: 'setBorder'; shapeId; border: Border }
| { type: 'setPhoto'; photo: Photo | null } | { type: 'setPhotoOpacity'; opacity: number }
```
- `addRectangle` stays and becomes a wrapper on `addShape`.
- Locking: every shape edit checks `isShapeLocked`, which includes the group's lock.
- Multi-shape actions are refused whole if any shape is locked or any outline would be refused. `attemptEdit` reports every touched shape for the red drawing.
- `joined`: every unlocked anchor of another shape within 0.5 projector px of the dragged anchor's start moves by the same amount. Holes count too. The drag answers for all of them.
- Reordering keeps groups together:
  - a grouped shape moves within its group only
  - `reorderGroup` moves the whole block
  - `group` places members at the topmost member's position
- `makeGrid`:
  - needs 4 corners, no curves and no holes
  - 2 to 256 cells, each 1–16 rows and columns
  - each cell copies the source (Greg's choice), and the original's source is let go
  - refused if past `MAX_SHAPES` or `MAX_SOURCES`
- `setBlocker` true clears the shape's source (orphans dropped).
- `setPhoto` is an undo step. Snapshots share the photo string.

**Tests:**
- One test per action.
- Lock through a group.
- Joined corners move together.
- A locked neighbour stays put.
- A refused joined move moves nothing.
- Grid over the limits is refused whole.
- Grid cells go into a new group, each with its own source.
- Mirror lands across the centre line.
- Duplicate of three shapes keeps their order.
- Group and reorder keep members contiguous.
- Deleting the last member drops the group.

### Task 4: Snap

**Files:** Create `src/map/snap.ts`. Test: `tests/map-snap.test.ts`.

```ts
export interface SnapResult { at: Point; target: { kind: 'point' | 'side' | 'edge' | 'centre'; at: Point } | null }
export function snapPoint(at: Point, show: { shapes: Shape[] }, exclude: { shapeIds: string[] }, reachPx: number): SnapResult;
export function snapMove(points: Point[], dx: number, dy: number, show, exclude, reachPx): { dx: number; dy: number; target: SnapResult['target'] };
export function joinedAnchors(show, shapeId: string, ring: number, index: number): { shapeId: string; ring: number; index: number }[];
```
- Priority is point, then side, then edge or centre.
- Hidden shapes and the excluded ones are ignored.
- Edges and the centre snap each axis on its own.

**Tests:**
- Snaps to a nearby point over a nearer side.
- Out of reach, nothing snaps.
- Edge snapping works on one axis only.
- Excluded shapes are ignored.
- `snapMove` moves the whole shape so its closest point lands.

### Task 5: Drawing, messages, wall

### Task 6: Compositor

**Files:** Modify `src/map/compositor.ts`. Create `src/map/edge.ts`, for the pure fade-picture key and size. Test: `tests/map-edge.test.ts`.
- Each shape's path is a cached `Path2D` (outline and holes), keyed by its geometry.
- Clipping uses `'evenodd'`.
- Soft edge:
  - The content is drawn into a scratch canvas at the box size.
  - It is cut with `destination-in` by the shape's fade picture.
  - The fade picture is made once per geometry and soft-edge key: fill, erode by `softEdge / 2` with a `destination-out` stroke, blur by `softEdge / 3`, then cut by the crisp path.
  - It is drawn at no more than half the projector's resolution, and stretched.
- Border: inside the clip, stroke the path at twice its width; glow uses `shadowBlur`.
- A Blocker fills black. With a soft edge it fills black through its fade picture.
- Solo and group visibility come through `shownOnWall`.
- `stats()` gains `edgeBuilds`, for checks.

**Tests (pure):**
- The fade key changes with the points, holes or soft edge, and not with the colour or source.
- The fade picture size is clamped.

### Task 7: Operator screen: tools and gestures

**Files:** Modify `src/ui/MapPanel.tsx`, `src/ui/useMap.ts`, `src/map/keys.ts`. Create `src/map/gestures.ts`. Tests: `tests/map-keys.test.ts` (new shortcut keys) and `tests/map-gestures.test.ts`.

**Tools:**
- Select (V), Rectangle (R), Triangle (T), Ellipse (E) and Pen (P), as header buttons and in the stage menu.
- Shift while dragging out a box makes it square.

**Pen:**
- A click adds a corner; click-and-drag adds a curve point.
- Enter, or clicking the first point, closes the shape. Escape cancels it.
- The preview is drawn on the operator screen only, until it closes.

**Points:**
- Double-click a side to add a point; double-click a point to remove it.
- Alt-click a point to switch it between corner and curve.
- The selected point's handles are drawn and can be dragged. Alt breaks the mirroring.
- Hole points are picked and edited like outline points.

**Snap and joined corners:**
- A Snap toggle sits under the stage, and its state is kept in the session.
- Ctrl while dragging switches snapping off and also moves one corner on its own.
- The snap target is drawn as a small cyan ring.

**Holes:** with a shape selected, Alt held at the start of a drawing tool's drag (or the Pen's first click) makes a hole in the selected shape.

**Selection:**
- Shift-click adds or removes a shape.
- A box dragged on empty stage selects the shapes wholly inside it.
- Escape clears the selection.
- Arrow keys nudge the selected point, or move every selected shape when no point is selected.
- ⌘A selects every shape.

**Moving and transforming:**
- Alt-drag on a shape duplicates it, or the selection, and drags the copies.
- The scale and turn box goes around the selection, with corner handles and a turn handle.
- Shift keeps the proportions when scaling, and turns in 15° steps.

**Pure helpers (`gestures.ts`):**
- `pick(at, show, selection, reachPx)`. It returns, in priority order: handle, point, side, transform handle, shape, or empty stage.
- `transformFor(handle, start, now, box, shift)`, which returns a `Matrix`.
