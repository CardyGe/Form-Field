Research register

Accessed 11 November 2026. Links support the factual descriptions; design lessons and proposed implementations are our interpretations. No independent popularity statistics are implied.

Evidence method

Current app renders and code are direct evidence. External evidence is identified row by row. TouchDesigner networks and MadMapper materials were not executed in licensed hosts. Browser samples of six commercial trailers/previews were visually inspected; this is not a claim to have watched every reference film. Paid assets were not acquired. No exhaustive search of the internet is possible; this register makes the actual coverage and gaps inspectable.

The research covers architectural shows, physical material art, generative composition, analog film, commercial loops, current 2026 TouchDesigner examples, official operator guides, actual MadMapper shader implementations and primary rendering/simulation literature. Older examples remain useful visual benchmarks; they are not presented as new releases.

MadMapper: inspected shader sources

The official repository tree was inventoried at commit d7ff211281f1878feeccd8ead05ce855c0eac5ee: 42 factory, 582 online-library and 14 demo fragment files under Materials/, plus separate laser folders. These are repository file counts, not the number of unique effects in the current online service. Thirty-one relevant shader implementations were selected for code inspection. Each link is pinned to that commit. Factory and community rows are distinguished. The material names are not evidence of physical simulation; several names are deliberately artistic.

Repository license metadata is not a blanket permission for every adapted shader: several headers credit original Shadertoy authors, and some say author unknown. These are study references. Any reuse would need a file-level license/provenance review; the plan defaults to original implementations and original media. Commercial loops are viewing benchmarks, not assets to redistribute.

Access gaps and exclusions

  • docs.derivative.ca rejected some requests; the official derivative.ca/UserGuide/ mirrors supplied the relevant operator pages. A Noise POP follow-up timed out; no specific Noise POP feature claim is relied on.
  • GitHub folder rendering was restricted in the web reader. The official GitHub tree API and raw commit URLs supplied the inventory and source, with hashes saved locally.
  • Lake Heckaman’s Realtime Caustics Part 2 was discovered behind a Patreon lock; only its public title/description were visible, so no claims about its private network are used.
  • Inigo Quilez’s distance-function article returned 403, and the attempted RayTK project site was unavailable. The accessible MadMapper raymarching source and tekt’s own Derivative post support the relevant comparisons instead.
  • A guessed TouchDesigner flow-field post URL failed; it is excluded. Aura Flow, Particle POP and the curl-noise paper provide verifiable alternatives.
  • No reference pack was benchmarked locally. No venue, physical projector, audience-view calibration or full film-by-film timed study was available.
