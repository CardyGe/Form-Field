# Super 8 Paint integration

The projector upgrade described in [Super 8 projector upgrade](super8-projector-upgrade.md) extends this original integration with continuous transport, gates, optical finish and more film wear. Timing and verification notes below record the original baseline.

Super 8 Paint is part of the existing Form & Field application. Add it in **Instruments → Super 8 Paint**, or filter Presets to **Super 8 Paint**. It uses the existing preview loop, layer compositor, Motion routes, project persistence, still renderer and native export pipeline.

## Modes and controls

- **Chromatic Staircase:** terraced plates of color with stepped boundaries and dragged pigment.
- **Paint Destruction:** broad brush swathes eroded by coarse pigment breakup and dry fibres.
- **Scratched Negative:** inverted stepped paint over dark film, with brighter scratches.
- **Cut-out Collage:** overlapping painted paper fragments with torn, stepped edges.

Shared controls cover geometry scale/steps, coverage, erosion, direction, paint texture/scale, dry brush, pigment bleed, motion, cycles, simulated film rate, feedback/spacing/zoom/rotation, scratches, grain, flicker and gate weave. The six palette roles are four paints, ink and paper. Substrate can be opaque paper or a transparent cutout. Existing blending, opacity, masks, transforms and color grading apply normally.

## Timing and feedback

The film clock uses the project’s actual rounded delivery duration and a whole number of film frames. It holds geometry, film defects and shared Motion routes together, independently of the preview refresh or export FPS. Integer mode, frame-rate, step and spacing controls remain discrete.

Feedback reconstructs six paint impressions (current plus five delayed samples) with decay and successive scale/rotation. Historical paint settings evaluate their own Motion routes. It is bounded feedback of this instrument’s source, before substrate and film finish. It does not accumulate other layers or retain a simulation buffer. Seek order, fresh renderers, stills and resumed jobs reproduce the same image, including when history wraps before frame zero.

Source pixels retain the existing associated linear RGBA contract; the shared compositor/finish produces straight-alpha finished linear SDR for the EXR cache. PNG and ProRes use the unchanged native encoding pipeline. Schema version 1 is extended with the new layer kind; existing layers and defaults remain intact. Native document/export validation accepts the new kind. The standalone render-proof fingerprint now traverses the source tree so transitive shader/motion changes invalidate stale caches.
